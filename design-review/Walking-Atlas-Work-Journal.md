# Walking Atlas 作業ジャーナル

記録日: 2026-11-13（JST）
対象: 旧散歩プラン共有サイトの姉妹ページ構築と旧97コースの新基準リルート

## 依頼と合意した方向

1. PCとスマートフォンで使いやすい Walking Atlas を新しく作り、既存の散歩先情報を整理する。
2. 先行公開中の `index.html` は残し、`atlas/` を GitHub Pages の姉妹ページとして公開する。
3. 旧97コースを、新A＝標準、新B＝延長、新C＝雨天の基準で調査・リルートし、検証できた新経路から表示を更新する。
4. 距離合わせのための不自然な往復、架空座標、直線フォールバックは採用しない。徒歩・鉄道・船・屋内歩行を混同しない。

旧 `Routing-Logic.md` のA/Bは「地図優先／下り回避優先」で、新A/B/Cとは意味が異なる。データの `variant` と `strategy` は分離した。旧ID、アンカー、原ページと旧GeoJSONは保存している。

## 監査と重要な判断

- 旧97件のうち73件に自動レビュー項目がある。形状上の同一区間反復10%超が52件、経由点と計算線の距離40m超が28件、距離調整の往復・周回を示す説明が34件、船・ケーブルカー・屋内動線の分離候補が7件。集計は重複し、現地品質の判定ではない。
- No.32の初期B案は、小石川後楽園の門間約406mの計算線のうち園内に入る部分が約2.9%だった。園内歩道の実在点を追加しても不自然な戻りが生じたため棄却。現在のBは園外を通る。
- No.22について、東京都公園協会の浜離宮案内は船着場を「下船のみ」と記載する。旧案の浜離宮からの乗船と浜松町付近の約1.9km往復延伸は新経路に流用しない。2026年11月11～27日には中の島園路の一部通行止めも告知されており、当日の公式情報が必要。
- 公開Valhallaはデモサービスのため、97件の一括経路計算には使わない。全件展開には利用条件の明確な徒歩ルーターと、公式資料・現地記録による個別設計が必要。

2. No.22の浜離宮から竹芝への徒歩動線を公式園路図・OSMで照合する。船を含む場合は別区間とし、A/B/CのGeoJSONと距離を作る前に通行条件を確定する。

5. 新A/B/Cの地図・現地レビューが済むまで、旧経路や調査案を検証済みと表示しない。

## 2026-11-14 反復経路と再生の続行

利用者から No.5 東京競馬場、No.7 高輪ゲートウェイ、No.8 上野ミュージアム、No.11 豊洲、No.17 麻布台、No.23 葛西臨海公園の旧線に反復の指摘があった。保存済み形状の自動監査では反復候補が順に約1510m、234m、1526m、919m、1068m、607m。`data/research/retrace-reports.json` と `retrace-clusters.json` に対象と位置付き候補を保存し、Atlasの旧経路に再設計警告を表示した。約100m以上の反復形状候補は旧97件中87件あるため、残りも台帳で追う。これは道路エッジの照合や安全な代替経路の発見ではない。

反復部分を形状から機械的に消す試算では、6件すべてで元の経由点の一部が線から離れた。地点・景観・出入口を失わずに直すため、新しい形状は採用していない。各コースは公式資料、道路網、現地条件を照合して個別に再設計する。新A/B/Cや一筆書き成立を主張しない。

No.7高輪ゲートウェイでは最大約202mの反復候補が品川駅付近にある。港区の2026年3月28日歩行者ルート切替案内を確認して `data/research/no-7-route-research.json` に記録した。これは高輪ゲートウェイ駅北側の東西連絡に関する資料で、品川駅付近の往復を解消する経路の証拠にはならない。新しい徒歩線は未生成。

「線を再生」は操作時だけ約9〜20秒で線を進め、線上に照合できた経由点で約2.2秒停止して吹き出しを表示する方式に変更した。「すぐ表示」で中断でき、動きを減らす設定では線を即時表示する。清澄白河No.47には地点ごとの説明を追加。旧地点の名称・説明が未照合の場合はその状態を明示する。`scripts/check-route-playback.mjs` で103形状の停止順と始終点を確認した。ブラウザーの実画面・操作は未確認。

同日の追加依頼で、Claudeへ引き継ぐための代表例として No.17・No.11・No.23 の徒歩計算候補を `data/candidates/` に作成。旧線の反復候補1,068m・919m・607mに対し、新候補の完全一致形状反復は3件とも0m。距離は2.118km・4.344km・2.242kmで、旧案の距離合わせや行き止まりの立ち寄りを本線から外した。いずれも距離目標より短く、道路エッジ・園路・入口・現地のレビューは未了。公開カタログには組み込まず、旧線も保持した。全97件の一覧と、経路再構築・チェックポイント再生・カードから地図への展開演出の指示を `design-review/` に保存した。
